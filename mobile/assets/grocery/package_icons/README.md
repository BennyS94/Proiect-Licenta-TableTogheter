# Grocery package icons

Expected package icon types:
- scale
- bag
- bottle
- carton
- tub
- pack
- piece
- pantry
- warning

Preferred file names:
- `package_scale.png`
- `package_bag.png`
- `package_bottle.png`
- `package_carton.png`
- `package_tub.png`
- `package_pack.png`
- `package_piece.png`
- `package_pantry.png`
- `package_warning.png`

Guidelines:
- simple line or filled icons
- transparent background
- consistent stroke and visual style
- 128 x 128 source size is enough
- expected UI display size is around 20-28 dp

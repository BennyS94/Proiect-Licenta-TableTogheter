# TableTogether Documentation

This folder contains public technical documentation for the TableTogether repository.

For the current implementation, start with:

- `architecture/current.md` - current system shape and responsibilities.
- `architecture/api_contract_v1.md` - backend/mobile API contract notes.
- `architecture/generator_v1_spec.md` - generator behavior and constraints.
- `architecture/sqlite_schema_v1.md` - local persistence schema notes.
- `architecture/mobile_backend_roadmap.md` - mobile/backend integration history and roadmap.

Supporting material:

- `api_examples/` - example request/response payloads.
- `decisions/` - persistent project decisions.
- `demo/` - local generator/demo notes.
- `archive/` - historical notes kept for context, not current source of truth.

The mobile app does not read files from this folder at runtime.
